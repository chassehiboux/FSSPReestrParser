# Иконка приложения

app.png — исходник, созданный встроенным imagegen. app.ico — тот же рисунок, преобразованный в Windows ICO с размерами 16, 24, 32, 48, 64, 128, 256 px и сохранением прозрачности. Иконка встроена в EXE при сборке rsrc и используется в интерфейсе.

Промпт:

> Use case: logo-brand. Asset type: Windows desktop application icon for a utility that downloads Excel data and prepares document registers. Create a single polished square app icon, simple bold shapes legible at 16px. A deep teal rounded square tile, centered overlapping white document sheets with two or three short teal table rows; a small emerald check mark badge at lower right. Front-facing flat vector-like raster art with subtle depth, crisp edges, generous padding. Transparent outside the rounded square. No text, no letters, no digits, no official government symbols, no seals, no gavel, no thin line details, no mockup background. Deliver only the icon.
