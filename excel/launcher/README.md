# Запуск реестров ФССП из Excel

Готовая книга: `Запуск_реестров_ФССП.xlsm`. Откройте её, разрешите макросы для доверенного файла и нажмите кнопку. Макрос для вызова из своей книги: `StartFSSPReestrParser`.

Сначала проверяется путь, запомненный приложением, затем папка установки, папка книги, рабочий стол и «Загрузки». Если приложение найдено, оно сразу запускается. Иначе последний опубликованный выпуск скачивается с GitHub в `%LOCALAPPDATA%\FSSPReestrParser\app`. Последующие обновления выполняет приложение.

Форма показывает этап, полосу скачивания, проценты, скачанные и общие МБ и среднюю скорость. Кнопка «Отмена» прерывает скачивание и удаляет незавершённый файл. Перед запуском проверяются размер, SHA-256 из того же выпуска и формат Windows x64. Установка не требует прав администратора.

Для встраивания в свою книгу:

1. Сохраните её как `.xlsm` и откройте редактор VBA (Alt+F11).
2. Через File → Import File импортируйте `mFSSPLauncher.bas`, `cFSSPDownload.cls`, `frmFSSPLauncher.frm`. Файл `.frx` должен лежать рядом с `.frm`; отдельно его импортировать не нужно.
3. Назначьте кнопке макрос `StartFSSPReestrParser` или `StartFSSPParser`. Работает и в надстройке `.xlam`.

Включать библиотеки в Tools → References не требуется. Скачивание использует встроенные Windows API, текстовые ответы — стандартный ADODB через `CreateObject`. Пользователям достаточно подключённой надстройки и разрешённых макросов.

При обновлении прежнего варианта остановите выполнение макроса кнопкой Reset в редакторе VBA. Замените `mFSSPLauncher` и `cFSSPDownload` новыми версиями (удалите прежние компоненты и импортируйте новые с теми же именами). UserForm не менялась. Удаление компонентов из проекта надстройки лучше выполнять после сохранения её резервной копии. Если WinHTTP ранее был добавлен вручную только для этого загрузчика, после замены он больше не нужен.

Поддерживается Excel с VBA7 (Office 2010 и новее, 32 или 64 бита) на Windows x64. Доступ к GitHub должен быть разрешён. Если скачивание завершилось ошибкой, причина остаётся на форме; повторите запуск после её устранения.

Готовые компоненты экспортированы самим Excel в нативной кодировке VBE. Исходники проекта хранятся в UTF-8. Сборщик `excel/build_launcher.py` требует установленный Excel и разрешённый доступ разработчика к объектной модели VBA; для обычного запуска готовой книги этот доступ не нужен. Настройки безопасности Office сборщик и макрос не меняют.
