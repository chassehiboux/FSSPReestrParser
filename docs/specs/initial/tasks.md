# Оставшиеся задачи

- Получить проверенную заказчиком редакцию Word-инструкции.
- После согласования внедрить постраничную инструкцию и первый запуск, кнопку «Инструкция» слева сверху.
- После согласования проверить и опубликовать новую версию.

Углублённая аналитика неточных кандидатов отложена по запросу заказчика.
