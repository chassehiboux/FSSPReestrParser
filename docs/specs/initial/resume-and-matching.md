# Согласованное сопоставление и повторный запуск

ФИО сравнивается без регистра, с равнозначными Е/Ё. В ФИО и номерах ИД/дела неразрывные пробелы равнозначны обычным, крайние и повторные пробелы убираются. Суммы совпадают при разнице строго меньше 0,01 рубля. Нормализация используется только для поиска; значения реестра берутся из исходника. Сначала основной ключ, затем номер дела исходника против номера ИД выгрузки. Разные даты рождения блокируют автоматическое принятие. На исследованном стандартном комплекте таких конфликтов нет.

Один исходник в родительской папке. Общий запуск использует только соседние папки «Исх.» и «Сверка». Полный комплект проверяется до формирования реестров; подтверждённые пустые отборы учитываются отдельно от отсутствующих файлов. Состояние должно переживать перезапуск приложения, сохранять подтверждение каждого файла и отличать старый комплект от новой полной выгрузки.

Частичный комплект: предложить довыгрузку недостающего или отмену. Полный комплект без готовых реестров: предложить создание реестров без скачивания. Готовый комплект: спросить о полной повторной выгрузке и создании реестров. При изменении исходника/настроек не использовать прежние подтверждения автоматически. Старые реестры сохраняются до формирования новых. Отмена ничего не перезаписывает.

## План

1. Нормализация ключей и десятичное сравнение сумм; проверка границы одной копейки и сохранения исходного текста.
2. Фиксированные соседние каталоги, журнал комплекта и блокировка, подтверждение продолжения/повтора.
3. Проверки восстановления, неполного комплекта, повторного запуска и сохранения реестров. Проверки Go на CI, сборка и новый релиз после успеха.
