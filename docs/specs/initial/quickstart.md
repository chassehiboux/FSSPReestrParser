# Начало работы

Проект создаётся в C:\chassehiboux\FSSPReestrParser. Требования: Windows 10/11 x64, установленный Chrome/Edge, доступ к корпоративной сети и GitHub.

Основной порядок: запустить приложение, при наличии обновления нажать ОК, нажать «Выгрузить ОВЗИД и создать реестры», выбрать исходный XLSX и месяц/год. Диалог открывает настроенную сетевую папку исходников независимо от предыдущего выбора Windows. При необходимости ввести логин и пароль учётной записи Windows; логин без `vostok\`. Выгрузка, проверка записи и создание реестров выполняются последовательно в одной панели. Результат — «Сверка» рядом с исходником, выгрузки внутри неё в «Исх.» без даты. Windows показывает эту папку как «Исх», без конечной точки.

При сбое программа делает до трёх попыток, сохраняя успешные выгрузки. Если завершить не удалось, нажмите «Продолжить». После перезапуска выберите тот же неизменённый исходник, месяц/год и настройки: незавершённый запуск продолжится. Техническое состояние находится в `%LOCALAPPDATA%\FSSPReestrParser\pipelines`, служебных файлов в «Исх.» нет.

Прежние кнопки доступны в разделе «Отдельные операции». Отдельная выгрузка по-прежнему сохраняет файлы в Downloads/Выгрузка ОВЗИД для реестров ФССП/дата.

После выгрузки нажмите «Создать реестры возбуждения и окончания», выберите месяц и год, исходный XLSX и папку с готовыми выгрузками ОВЗИД, затем «ОК». Этапы и счётчики появятся снизу. Рядом с исходником создаётся новая подпапка «Сверка»: три основных реестра по ИД, аналитика и два дополнительных реестра (возбуждение и окончание) для строк, не совпавших по ИД, но найденных по номеру дела с ДР. Всего шесть файлов. Прежние комплекты сохраняются в своих подпапках. «Открыть папку» показывает готовый результат.

Администрирование общих блоков доступно dzuikevich. Подписи настроек нет по решению заказчика.
# Личные настройки и Excel

В админке можно выключить аналитику и оба дополнительных реестра `_по_делу`. Три основных файла остаются включёнными. «Сохранить только для меня» создаёт личный профиль в локальной папке программы; «Сохранить для всех» публикует текущие настройки и отключает личный профиль автора. «Использовать общие» возвращает к общим настройкам. Другие пользователи с личным профилем сохраняют свои настройки до самостоятельного возврата к общим.

Готовый загрузчик без ручных References: `output/excel-launcher-no-references/Запуск_реестров_ФССП.xlsm`; пакет для импорта в свою книгу или `.xlam`: `output/excel-launcher-no-references/Excel_запуск_ФССП.zip`. Подробная инструкция — `excel/launcher/README.md`. Макрос: `StartFSSPReestrParser` или `StartFSSPParser`. Сборка через установленный Excel: `python -X utf8 excel/build_launcher.py --output-dir output/excel-launcher-no-references`; проверка импорта в чистую `.xlam` и скачивания: `python -X utf8 excel/test_launcher.py --package-dir output/excel-launcher-no-references`.
