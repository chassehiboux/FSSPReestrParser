# Начало работы

Проект создаётся в C:\chassehiboux\FSSPReestrParser. Требования: Windows 10/11 x64, установленный Chrome/Edge, доступ к корпоративной сети и GitHub.

Порядок для пользователя: запустить приложение, при наличии обновления нажать ОК, нажать «Выгрузить ОВЗИД», при необходимости ввести учётные данные Пирамиды. Результат появится в системной Downloads/Выгрузка ОВЗИД для реестров ФССП/дата.

После выгрузки нажмите «Создать реестры возбуждения и окончания», выберите месяц и год, исходный XLSX и папку с готовыми выгрузками ОВЗИД, затем «ОК». Этапы и счётчики появятся снизу. Рядом с исходником создаётся новая подпапка «Сверка» с тремя основными реестрами по ИД, дополнительным реестром возбуждения с ДР по номеру дела и аналитикой — всего пять файлов. Прежние комплекты сохраняются в своих подпапках. «Открыть папку» показывает готовый результат.

Администрирование общих блоков доступно dzuikevich. Подписи настроек нет по решению заказчика.
