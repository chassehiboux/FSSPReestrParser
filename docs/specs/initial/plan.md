# План реализации

Дополнение по номеру дела: независимый индекс при том же чтении выгрузок → отдельный пятый реестр возбуждения → этап и счётчик по делу → проверки расхождения ИД, конфликтов ДР, неизменности прежних файлов и реальный прогон → сборка EXE.

1. Обследовать исходники PyramidReports и живую форму через сохранённый Chrome. Переносим правила, а не Python runtime. Новый Go runner необходим по прямому запросу самостоятельной архитектуры.
2. Проверить Go/Rod/Walk на сквозном прототипе с установленным браузером.
3. Разделить модули: model/config, Windows integration, browser/auth/form, queue/download, native UI/admin, releases/updater.
4. Реализовать основной блок, изоляцию контекстов, очередь 3, плоские файлы и прогресс.
5. Конструктор блоков, каталоги департаментов, публикация обычного JSON на SMB и кэш.
   Панель прогресса раскрывается внизу, состояния окрашены. Дневная папка поддерживает довыгрузку по проверенным именам XLSX. Общий кэш по областям устаревает после 7 суток, обновление ручное по всем настроенным базам и департаментам. Уведомления Windows и фоновая проверка релизов каждые 30 минут.
6. Подготовить публичный репозиторий и GitHub Actions для сборки. Настройки среды в локальном bootstrap, рабочие пути не публиковать.
7. Проверить обновление и перезапуск локально; выпустить первую сборку после проверок.

Сборка нового проекта отдельная: deploy_and_build.py PyramidReports не используется и не изменяется. Новые зависимости фиксируются go.mod/go.sum, устанавливаются в окружении. GUI манифест встраивается при сборке.

## Вторая кнопка — первый этап

1. Добавить Excelize для чтения XLSX и работы с встроенными исходными шаблонами.
2. Реализовать точный индекс, безопасное разрешение ДР и четыре выходных файла с сохранением типов и порядка строк.
3. Добавить диалог месяца/года/путей и встроенную таблицу пяти этапов с цветами, счётчиками и отменой.
4. Проверить граничные случаи и реальный комплект 940 / 940 / 2 436 / 3 376, собрать EXE для локальной проверки. Углублённый поиск неточных кандидатов отложить.

## Исправление запуска выгрузки и лимита

Убрать лишнюю подготовительную вкладку и повторную навигацию после выбора департамента, передавать подготовленную вкладку первому заданию. Разрешить 20 активных заданий в админке и проверке общих настроек. Проверить маршрутизацию, сохранение первого target/context, ошибки страницы и лимит очереди на 20 заданий, затем собрать исправленный EXE.
