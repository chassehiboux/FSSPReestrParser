# Правила проекта

- Ответы и документация — на русском. Текст — UTF-8 без BOM.
- Новый самостоятельный проект; PyramidReports используется только как источник опыта, его файлы не изменять.
- Изменения: спецификация → план → задачи → реализация. Выполненные задачи удалять из tasks.md.
- Windows 10/11 x64, Go + Rod + Walk, установленный Chrome/Edge. Не скачивать браузер автоматически.
- Выгрузка только отправляет запрос. Общая очередь заранее подписывается на скачивание и сохраняет результат. По умолчанию до 3 активных заданий до завершения сохранения; лимит настраивается администратором.
- Результаты: все XLSX непосредственно в Downloads/Выгрузка ОВЗИД для реестров ФССП/yyyy.mm.dd. Никаких реестров, журналов и служебных файлов в папке выгрузки.
- Повторный запуск в тот же день предлагает полную перевыгрузку, довыгрузку недостающих или отмену. Прежний файл сохраняется до успешного обновления; подтверждённый пустой отбор убирает устаревший файл.
- Прогресс раскрывается снизу в главном окне отдельно для каждой операции, без столбца «Блок», состояния окрашены. Есть системные уведомления и фоновая проверка выпусков каждые 30 минут.
- Общий кэш полей раздельный по базе и департаменту, с датой. В админке возраст более 7 дней требует надписи и ручной кнопки «Обновить» для всех настроенных областей; частичный успех сохранять.
- Настройки общие на SMB, без подписи и без настройки ACL. Админка проверяет учётную запись Windows. Пароли, cookies, рабочие конфиги и выгрузки не публиковать.
- Региональный профиль содержит ссылки на базы, департаменты и блоки. В первой версии только Курган.
- Коммиты — на русском; включать только изменения задачи.
